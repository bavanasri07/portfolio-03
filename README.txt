BAVANA SRI SIVAKUMAR — CREATIVE PORTFOLIO

QUICK START
1. Extract the ZIP folder.
2. Open index.html in a modern browser to preview the portfolio.
3. To publish it, upload the contents of this folder to a static hosting service (for example GitHub Pages, Netlify or Vercel).

EDITING
- Update text and links in index.html.
- Update colours and layout in styles.css.
- Carousel controls and mobile navigation are in script.js.
- Replace images in assets/ while keeping the filenames, or update the corresponding paths in index.html/script.js.

NOTES
